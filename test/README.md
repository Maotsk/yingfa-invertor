test/loopback.yaml

Тестовая прошивка для проверки UART-цепочки инвертора Yingfa.

Использование:
  1. Залить на ESP8266 через ESPHome Dashboard.
  2. Поставить перемычку TX-RX на ESP (тест микроконтроллера).
  3. Посмотреть логи: если строка вернулась — узел жив.
  4. Переставить перемычку на модуль RS232-TTL (T1 OUT - R1 IN) и проверить ещё раз — теперь тестируется преобразователь.

ВАЖНО: не заливайте одновременно с основной прошивкой yingfa-invertor.yaml — они используют одни и те же пины.

 test/protocol-probe.yaml

 Тестовая прошивка для разведки протокола инвертора Yingfa.

 Использование:
   1. Подключить инвертор к модулю RS232-TTL, модуль — к ESP.
   2. Залить эту прошивку.
   3. Нажать кнопку "Send QPIGS" (или дождаться автозапуска).
   4. Посмотреть в логах сырые байты ответа инвертора.

 Что проверяем:
   - Инвертор вообще отвечает?
   - Скорость 2400 бод — верная?
   - Формат пакета: '(' + ASCII + CRC + 0x0D
   - Пауза между байтами (инвертор отвечает не мгновенно)
   - Корректность CRC

 ВАЖНО: не заливайте одновременно с основной прошивкой yingfa-invertor.yaml.
